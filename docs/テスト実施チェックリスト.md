## 🚀 テスト実行手順（ケースごと）

### **手順1: 画像準備**
1. ブラウザでケース画像（例：001.jpg）を開く
2. 画像が画面に適切なサイズで表示されることを確認
3. 必要に応じてズーム調整（100%推奨）

### **手順2: OCR実行**
1. `Ctrl+Alt+C`キーを押下
2. マウスで文字領域を矩形選択（左上→右下にドラッグ）
3. 赤い矩形線が表示されることを確認
4. OCR処理完了音またはクリップボードコピー通知を待つ

### **手順3: CER計算**
1. **CREテスター**を前面に表示
2. 「期待値テキスト」に正解を入力（HTMLから正確にコピー）
3. 「OCR結果テキスト」に`Ctrl+V`でOCR結果を貼り付け
4. **「CER計算」**ボタンをクリック
5. 結果を上記記録表に転記

### **手順4: 特別条件チェック**
- **008/010**: 空白保持率が99%以上か確認
- **010**: URL文字列が完全一致しているか目視確認
- **001/009**: レイテンシが1500ms以下か確認

### **手順5: 保存・次ケースへ**
1. **「JSONL保存」**ボタンで結果を記録
2. **「クリア」**ボタンで次ケース準備
3. 上記記録表にメモを記入
4. 次のケースに進む

## 📈 結果分析のポイント

### **不合格ケースの分析**
1. **小文字（003）**: フォントサイズが小さすぎる可能性
2. **低コントラスト（005/012）**: 画像の明度調整が必要
3. **傾き（007）**: 画像の回転補正が必要
4. **構造保持（008/010）**: 空白・記号の認識精度が課題

### **改善提案**
- CER > 上限の場合: 該当タグの特性に応じた前処理改善
- 平均CER > 5%の場合: 全体的な認識精度の向上が必要
- レイテンシ > 1500msの場合: ネットワークまたはAPI呼び出し最適化
