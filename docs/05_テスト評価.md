## 🎯 テスト条件（すべて固定）

### **入力データ**
- **画像**: set1の12画像（001-012.jpg/png）
- **基準**: manifest.csvの`file, lang, tags, chars_expected`
- **正解**: HTML内「正解テキスト」欄（空白・改行保持）

### **実行環境**
- **前処理**: アプリ標準設定（手動補正なし）
- **解像度**: スクリーンショット原寸
- **DPI**: 実運用環境に固定
- **リトライ**: API失敗時は既定の指数バックオフのみ

### **測定指標**
- **CER**: Levenshtein距離 ÷ 正解文字数
- **正確率**: 1 - CER
- **空白保持率**: 空白文字の一致率（008,010用）
- **URL/コード厳密一致**: 完全一致チェック（010用）
- **レイテンシ**: 1ケースあたり処理時間

## 🚀 テスト実施手順（中学生向け）

### **準備（5分）**

#### 1. アプリとツールの起動
```powershell
# 1. OcrSnippingAppを起動
cd "C:\Users\user\Documents\Projects\OcrSnippingApp"
dotnet run

# 2. CREテスターを起動
cd "C:\Users\user\Documents\Projects\OcrSnippingApp\tools\CreTester"  
dotnet run
```

#### 2. テストファイルの準備
- **manifest.csv**: ケース001〜012の期待値表
- **正解HTML**: 各ケースの「正解テキスト」欄
- **画像ファイル**: 001.jpg 〜 012.png

### **実行（ケースあたり2分）**

#### 📝 **ステップ1: 画像キャプチャ**
1. テスト画像（例：001.jpg）をブラウザで開く
2. `Ctrl+Alt+C`でOcrSnippingAppを起動
3. 画像の文字部分を矩形選択
4. OCR処理の完了を待つ（赤線→クリップボードコピー音）

#### 📊 **ステップ2: CER測定**
1. **CREテスター**の「期待値テキスト」に正解を入力
2. 「OCR結果テキスト」に`Ctrl+V`で貼り付け
3. **「CER計算」**ボタンをクリック
4. 結果をチェック：
   - **CER**: 上記表の上限以下か？
   - **特別条件**: 空白保持率・URL一致・レイテンシ
5. **「JSONL保存」**ボタンで記録

#### 📈 **ステップ3: 判定記録**
```
ケース001: CER 1.2% ✅ (上限2%) / レイテンシ 245ms ✅ (上限1500ms)
ケース002: CER 4.8% ✅ (上限5%)
ケース003: CER 9.1% ❌ (上限8%) ← 要改善
...
```

# test_ocr_suite.ps1
$testCases = @(
    @{ID="001"; Name="JP_clean"; GroundTruth="C:\path\to\001_JP_clean.txt"}
    @{ID="002"; Name="JP_dense"; GroundTruth="C:\path\to\002_JP_dense.txt"}
    # ... 省略 ...
)

foreach ($test in $testCases) {
    Write-Host "=== テスト $($test.ID): $($test.Name) ===" -ForegroundColor Cyan
    
    # OCR実行指示をユーザーに表示
    Write-Host "画像を選択してください: $($test.ID)_$($test.Name).png"
    Read-Host "準備ができたらEnterを押してください"
    
    # クリップボードからOCR結果を取得
    $ocrResult = Get-Clipboard
    
    # グラウンドトゥルースと比較
    $expected = Get-Content $test.GroundTruth -Raw
    
    # CER計算 (簡易版)
    $cer = Compare-Strings $ocrResult $expected
    
    Write-Host "CER: $cer%" -ForegroundColor $(if($cer -lt 5){'Green'}elseif($cer -lt 10){'Yellow'}else{'Red'})
    
    # 結果保存
    $ocrResult | Out-File "results\$($test.ID)_result.txt"
}
