## 🎯 プロジェクト概要

Google Cloud Vision APIを使用したWindows用OCRスクリーンキャプチャツール。Ctrl+Alt+Cで画面の任意範囲を選択し、認識したテキストを自動的にクリップボードにコピーします。

### 🚀 主要機能
- ✨ ホットキーによる瞬間スクリーンキャプチャ
- 🤖 Google Cloud Vision API による高精度OCR
- 📋 クリップボード自動連携
- 🔧 エラー分類・リトライシステム
- 📊 信頼度評価・品質管理

### 🚀 **v2.0 新機能**
- ✨ **ErrorClassifier**: 実行時例外のOcrIssue分類
- ✨ **VisionConfidence**: 単語レベル平均信頼度算出
- ✨ **RetryAsync**: 429/5xx系エラーの指数バックオフ
- ✨ **タイムアウト処理**: CancellationTokenによる時間制限
- ✨ **通知アイコン切り替え**: Info/Warning/Error対応
