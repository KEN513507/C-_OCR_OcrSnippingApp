## 5. エラーハンドリング・メッセージ

### エラーコード一覧

| コード | 種別 | メッセージ |
|--------|------|------------|
| E-01 | 認証不可（ADC未設定） | 認証情報が見つかりません。環境変数を確認してください。 |
| E-02 | API 403/権限 | 権限不足。サービスアカウントのロールを確認してください。 |
| E-03 | API 429/クォータ | クォータ超過。時間をおいて再実行してください。 |
| E-04 | ネットワーク断 | ネットワークに接続できません。 |
| E-05 | ホットキー衝突 | ホットキー登録に失敗。別の組み合わせを設定してください。 |
| E-06 | 矩形が小さい | 無処理で終了（通知省略または軽いトースト） |
