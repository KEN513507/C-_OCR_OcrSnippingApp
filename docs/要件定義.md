# OcrSnippingApp

OCR機能付きスクリーンキャプチャアプリケーション

## 概要

**OcrSnippingApp** は、画面の任意領域を矩形選択し、Google Cloud Vision APIを使用してOCR処理を行い、認識したテキストをクリップボードに出力するWindowsアプリケーションです。

## 技術仕様

- **対象OS**: Windows 11
- **フレームワーク**: .NET 8.0-windows (WinForms)
- **外部API**: Google Cloud Vision API
- **認証方式**: サービスアカウントJSON (環境変数 `GOOGLE_APPLICATION_CREDENTIALS`)
- **ネットワーク**: インターネット接続必須

## 機能一覧

### 基本機能
- **F-01**: バックグラウンド常駐・タスクトレイ表示
- **F-02**: カスタマイズ可能なグローバルホットキー (既定: `Ctrl+Alt+C`)
- **F-03**: 半透明オーバーレイによる矩形選択UI
- **F-04**: マルチモニタ・DPI対応スクリーンキャプチャ
- **F-05**: 効率的なOCRクライアント管理

### OCR機能
- **F-06**: DocumentTextDetection / TextDetection 切り替え対応
- **F-07**: 認識結果のクリップボード自動コピー
- **F-08**: 文字検出失敗時の通知表示

### システム機能
- **F-09**: 二重起動防止 (Mutex使用)
- **F-10**: 設定の永続化 (ホットキー、モード、通知設定)

## 前提条件

- シングルユーザー環境
- 管理者権限不要
- Google Cloud Vision API の有効化とサービスアカウント設定
