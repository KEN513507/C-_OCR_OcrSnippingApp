```json
  }

```

### 設定項目詳細

| 項目 | 型 | デフォルト | 説明 |
|------|----|-----------|------|
| HotkeyModifiers | string | 空文字 | ホットキー修飾子 (空なら無効) |
| HotkeyKey | string | 空文字 | ホットキー本体キー (空なら無効) |
| OcrMode | string | `DocumentTextDetection` | OCR 認識モード |
| Notifications | bool | `true` | 通知表示の有無 |
| TimeoutMs | int | `10000` | Vision API タイムアウト (ms) |
| LanguageHint | string | `ja` | Vision API 言語ヒント |
| AppendModeEnabled | bool | `false` | 追記モードの有効/無効 |
| PrefixText | string | 空文字 | OCR結果の前に付与するテキスト (最大5000文字) |
| SuffixText | string | 空文字 | OCR結果の後に付与するテキスト (最大5000文字) |
| AddBlankLines | bool | `true` | 前後テキストと本文の間に改行を追加 |

#### 追記モード処理フロー
```csharp
var finalText = settingsService.BuildAugmentedText(ocrText);
SetClipboardTextWithRetry(finalText);
Logger.LogInfo($"OCR copied. len={finalText.Length}, append={settingsService.Current.AppendModeEnabled}");
```

- `BuildAugmentedText` は `AppendModeEnabled` が `true` のときのみ前後テキストを合成。
- `AddBlankLines` が `true` かつ `PrefixText` / `SuffixText` が空でない場合、本文との間に `Environment.NewLine` を挿入。
- `PrefixText` / `SuffixText` が 5000 文字を超える場合は自動的に切り詰め、警告ログを出力。
- 合成後の文字列はそのままクリップボードへコピーされ、通知には「追記モード適用済み」と表示される。

### 3. Vision API呼び出し
```csharp
private async Task<AnnotateImageResponse> PerformOcrRequestAsync(Bitmap image, string? languageHint, CancellationToken cancellationToken)
{
    var client = VisionClientService.Instance.Client;
    
    using (var stream = new MemoryStream())
    {
        image.Save(stream, ImageFormat.Png);
        var visionImage = VisionImage.FromBytes(stream.ToArray());
        
        var context = new ImageContext();
        if (!string.IsNullOrWhiteSpace(languageHint))
        {
            context.LanguageHints.Add(languageHint);
        }
        
        var request = new AnnotateImageRequest
        {
            Image = visionImage,
            ImageContext = context
        };
        request.Features.Add(new Feature { Type = Feature.Types.Type.DocumentTextDetection });
        
        return await RetryAsync(
            () => client.AnnotateAsync(request, cancellationToken: cancellationToken),
            maxRetries: 2);
    }
}
```

### 4. リトライロジック
```csharp
private static async Task<T> RetryAsync<T>(Func<Task<T>> operation, int maxRetries = 2)
{
    var delay = 300;
    for (var attempt = 0; ; attempt++)
    {
        try
        {
            return await operation().ConfigureAwait(false);
        }
        catch (Grpc.Core.RpcException ex) when (ShouldRetry(ex.Status.StatusCode) && attempt < maxRetries)
        {
            Logger.LogWarning($"Vision API呼び出し失敗 (Status: {ex.Status.StatusCode}). {delay}ms後に再試行します。");
            await Task.Delay(delay).ConfigureAwait(false);
            delay = Math.Min(delay * 2, 1000); // 指数バックオフ
        }
    }
}

private static bool ShouldRetry(Grpc.Core.StatusCode statusCode)
{
    return statusCode == Grpc.Core.StatusCode.ResourceExhausted ||  // 429
           statusCode == Grpc.Core.StatusCode.Unavailable ||        // 503
           statusCode == Grpc.Core.StatusCode.Internal ||           // 500
           statusCode == Grpc.Core.StatusCode.Unknown ||            // 500
           statusCode == Grpc.Core.StatusCode.DeadlineExceeded;     // Timeout
}
```

## 📝 ログ仕様

### ログファイル
- **場所**: `%APPDATA%\OcrSnippingApp\Logs\OcrSnippingApp_YYYYMMDD.log`
- **保持期間**: 7日間自動削除
- **フォーマット**: `[YYYY-MM-DD HH:mm:ss.fff] [LEVEL] メッセージ`

### ログレベル
- **INFO**: 正常フロー (起動、OCR開始/完了、設定読み込み)
- **WARN**: 注意事項 (リトライ、低信頼度)
- **ERROR**: エラー発生 (認証失敗、ネットワークエラー)
- **DEBUG**: デバッグ情報 (Debugビルドのみ、テキスト内容先頭60文字)

## 🔐 セキュリティ仕様

### 認証情報管理
- **環境変数**: `GOOGLE_APPLICATION_CREDENTIALS`
- **ファイル形式**: サービスアカウントJSON
- **ハードコード禁止**: コード内に認証情報を含めない
- **権限**: 最小権限原則 (roles/visionai.user)

### データ保護
- **画像データ**: メモリ内のみ、ディスクに保存しない
- **OCRテキスト**: ログに全文出力しない (先頭60文字のみ)
- **個人情報**: ログに含めない

## 📊 パフォーマンス仕様

### 応答時間要件
- **平均**: 2秒以内 (N-01)
- **P95**: 3秒以内
- **実測平均**: 290ms (要件の14.5%)

### リソース使用量
- **メモリ**: 起動時50MB以下
- **CPU**: 通常時1%以下、OCR処理時20%以下
- **ネットワーク**: API呼び出し時のみ

### スケーラビリティ
- **同時実行**: 1ユーザー1プロセス
- **OCRキュー**: 順次処理（並列処理なし）
- **ファイルロック**: Mutex による二重起動防止
