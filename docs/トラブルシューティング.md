# トラブルシューティングガイド

## 🚀 起動確認手順

### 1) プロセスクリーンアップ

```powershell
# 既存プロセスを完全終了
Get-Process OcrSnippingApp -ErrorAction SilentlyContinue | Stop-Process -Force

# Mutex残留対策: 念のため再起動確認
Start-Sleep -Seconds 1
Get-Process OcrSnippingApp -ErrorAction SilentlyContinue
# → 何も表示されなければOK
```

### 2) ログ確認（起動直後の例外検出）

```powershell
# ログファイルパス
$log = Join-Path $env:APPDATA "OcrSnippingApp\Logs\OcrSnippingApp_$(Get-Date -Format 'yyyyMMdd').log"

# アプリ起動
cd C:\Users\user\Documents\Projects\OcrSnippingApp
Start-Process ".\src\OcrSnippingApp\bin\Debug\net8.0-windows\OcrSnippingApp.exe"

# 2秒待機してログ確認
Start-Sleep -Seconds 2

# エラー/例外の確認
if(Test-Path $log){
  Write-Host "`n=== 起動ログ（エラー/例外/警告） ===" -ForegroundColor Yellow
  Get-Content $log -Tail 200 | Select-String 'ERROR|例外|fatal|起動|初期化'
  
  Write-Host "`n=== ホットキー登録状況 ===" -ForegroundColor Yellow
  Get-Content $log -Tail 200 | Select-String 'Hotkey|ホットキー|ウィンドウハンドル'
  
  Write-Host "`n=== アイコン読み込み ===" -ForegroundColor Yellow
  Get-Content $log -Tail 200 | Select-String 'アイコン|Icon'
} else { 
  Write-Host "ログなし: $log" -ForegroundColor Red
  Write-Host "アプリが即座に終了した可能性があります（参照設定不足など）" -ForegroundColor Red
}
```

### 3) 設定ファイル確認

```powershell
# 実行中のEXEが読み込む設定ファイルを確認
$proc = Get-Process OcrSnippingApp -ErrorAction SilentlyContinue
if($proc){
  $exe = $proc.MainModule.FileName
  $cfg = Join-Path (Split-Path $exe) 'appsettings.json'
  
  Write-Host "`n=== 使用中の設定ファイル ===" -ForegroundColor Cyan
  Write-Host "EXE: $exe"
  Write-Host "CFG: $cfg"
  Write-Host ""
  
  if(Test-Path $cfg){
    Write-Host "--- 設定内容 ---" -ForegroundColor Green
    $json = Get-Content $cfg -Raw | ConvertFrom-Json
    $json.OcrSnipping | Format-List
  } else {
    Write-Host "設定ファイルが見つかりません: $cfg" -ForegroundColor Red
  }
} else {
  Write-Host "OcrSnippingApp は起動していません" -ForegroundColor Red
}
```

### 4) リアルタイムログ監視（ホットキーテスト用）

```powershell
# ログをリアルタイム監視
$log = Join-Path $env:APPDATA "OcrSnippingApp\Logs\OcrSnippingApp_$(Get-Date -Format 'yyyyMMdd').log"
Write-Host "ログ監視中: $log" -ForegroundColor Cyan
Write-Host "Ctrl+Shift+E を押してホットキーをテストしてください..." -ForegroundColor Yellow
Get-Content $log -Wait -Tail 20 -Encoding UTF8 | Select-String 'Hotkey|WM_HOTKEY|Vision|クリップボード|OCR'
```

## 🔧 典型的な問題と対処

### ❌ 問題1: アプリが起動しない（タスクトレイにアイコンが出ない）

**原因候補:**
- Mutex残留（前回の異常終了）
- 参照設定不足（即例外終了）
- GOOGLE_APPLICATION_CREDENTIALS 未設定

**対処:**
```powershell
# 1) プロセスを完全終了
Get-Process OcrSnippingApp -ErrorAction SilentlyContinue | Stop-Process -Force

# 2) 環境変数確認
if(-not $env:GOOGLE_APPLICATION_CREDENTIALS){
  Write-Host "GOOGLE_APPLICATION_CREDENTIALS が未設定です" -ForegroundColor Red
  Write-Host "以下のコマンドで設定してください:" -ForegroundColor Yellow
  Write-Host '$env:GOOGLE_APPLICATION_CREDENTIALS = "C:\Keys\ocr-snipping-app.json"'
} else {
  Write-Host "認証ファイル: $env:GOOGLE_APPLICATION_CREDENTIALS" -ForegroundColor Green
  if(Test-Path $env:GOOGLE_APPLICATION_CREDENTIALS){
    Write-Host "ファイル存在: OK" -ForegroundColor Green
  } else {
    Write-Host "ファイルが見つかりません" -ForegroundColor Red
  }
}

# 3) 再起動
Start-Process ".\src\OcrSnippingApp\bin\Debug\net8.0-windows\OcrSnippingApp.exe"
```

### ❌ 問題2: ホットキーが動作しない

**原因候補:**
- ウィンドウハンドル未作成時に登録
- 他のアプリがホットキーを使用中（Win32Error=1409）
- 設定ファイルの読み込み失敗

**対処:**
```powershell
# ログでWin32エラーコード確認
$log = Join-Path $env:APPDATA "OcrSnippingApp\Logs\OcrSnippingApp_$(Get-Date -Format 'yyyyMMdd').log"
Get-Content $log | Select-String 'Win32Error|ホットキー登録|WM_HOTKEY' | Select-Object -Last 10

# Win32Error=1409 の場合: 他のアプリが使用中
# → appsettings.json でホットキーを変更（例: Ctrl+Shift+O）
```

**ホットキー変更手順:**
```powershell
$cfg = ".\src\OcrSnippingApp\bin\Debug\net8.0-windows\appsettings.json"
$json = Get-Content $cfg -Raw | ConvertFrom-Json
$json.OcrSnipping.HotkeyModifiers = "Ctrl+Shift"
$json.OcrSnipping.HotkeyKey = "O"  # E → O に変更
$json | ConvertTo-Json -Depth 8 | Set-Content $cfg -Encoding UTF8

# アプリ再起動
Get-Process OcrSnippingApp -ErrorAction SilentlyContinue | Stop-Process -Force
Start-Process (Split-Path $cfg)\OcrSnippingApp.exe
```

### ❌ 問題3: アイコンがカスタムアイコンにならない

**原因:**
- `appicon.ico` が bin フォルダにコピーされていない

**対処:**
```powershell
# アイコンファイルの存在確認
$iconSrc = ".\src\OcrSnippingApp\appicon.ico"
$iconDst = ".\src\OcrSnippingApp\bin\Debug\net8.0-windows\appicon.ico"

if(Test-Path $iconSrc){
  Copy-Item $iconSrc $iconDst -Force
  Write-Host "アイコンをコピーしました: $iconDst" -ForegroundColor Green
  
  # アプリ再起動
  Get-Process OcrSnippingApp -ErrorAction SilentlyContinue | Stop-Process -Force
  Start-Process (Split-Path $iconDst)\OcrSnippingApp.exe
} else {
  Write-Host "ソースアイコンが見つかりません: $iconSrc" -ForegroundColor Red
}
```

### ❌ 問題4: Vision API 通信ログが出ない

**原因:**
- OCRを実行していない
- ログレベルがINFOになっていない

**対処:**
```powershell
# OCR実行後にログ確認
$log = Join-Path $env:APPDATA "OcrSnippingApp\Logs\OcrSnippingApp_$(Get-Date -Format 'yyyyMMdd').log"

Write-Host "1. ホットキー（Ctrl+Shift+E）でOCRを実行してください" -ForegroundColor Yellow
Write-Host "2. テキストを選択してEnterを押してください" -ForegroundColor Yellow
Write-Host ""
Write-Host "Vision APIログを確認中..." -ForegroundColor Cyan

Get-Content $log -Wait -Tail 30 -Encoding UTF8 | Select-String 'Vision|OCR|retry|クリップボード'
```

## 📋 完全な診断スクリプト

```powershell
# OcrSnippingApp 完全診断スクリプト
$ErrorActionPreference = "Continue"

Write-Host "`n========================================" -ForegroundColor Cyan
Write-Host "OcrSnippingApp 診断スクリプト" -ForegroundColor Cyan
Write-Host "========================================`n" -ForegroundColor Cyan

# 1) プロセス確認
Write-Host "[1] プロセス確認" -ForegroundColor Yellow
$proc = Get-Process OcrSnippingApp -ErrorAction SilentlyContinue
if($proc){
  Write-Host "  ✓ 起動中: PID=$($proc.Id), Memory=$([math]::Round($proc.WS/1MB, 2))MB" -ForegroundColor Green
  $exe = $proc.MainModule.FileName
  Write-Host "  ✓ EXE: $exe" -ForegroundColor Green
} else {
  Write-Host "  ✗ 未起動" -ForegroundColor Red
}

# 2) 設定ファイル確認
Write-Host "`n[2] 設定ファイル確認" -ForegroundColor Yellow
if($proc){
  $cfg = Join-Path (Split-Path $exe) 'appsettings.json'
  if(Test-Path $cfg){
    Write-Host "  ✓ 設定: $cfg" -ForegroundColor Green
    $json = Get-Content $cfg -Raw | ConvertFrom-Json
    Write-Host "  - ホットキー: $($json.OcrSnipping.HotkeyModifiers)+$($json.OcrSnipping.HotkeyKey)"
    Write-Host "  - 追記モード: $($json.OcrSnipping.AppendModeEnabled)"
  } else {
    Write-Host "  ✗ 設定ファイルなし: $cfg" -ForegroundColor Red
  }
} else {
  Write-Host "  - アプリ未起動のためスキップ" -ForegroundColor Gray
}

# 3) アイコンファイル確認
Write-Host "`n[3] アイコンファイル確認" -ForegroundColor Yellow
if($proc){
  $iconPath = Join-Path (Split-Path $exe) 'appicon.ico'
  if(Test-Path $iconPath){
    $iconSize = [math]::Round((Get-Item $iconPath).Length/1KB, 2)
    Write-Host "  ✓ アイコン: $iconPath ($iconSize KB)" -ForegroundColor Green
  } else {
    Write-Host "  ✗ アイコンなし: $iconPath" -ForegroundColor Red
  }
} else {
  Write-Host "  - アプリ未起動のためスキップ" -ForegroundColor Gray
}

# 4) 環境変数確認
Write-Host "`n[4] Google認証情報確認" -ForegroundColor Yellow
if($env:GOOGLE_APPLICATION_CREDENTIALS){
  Write-Host "  ✓ GOOGLE_APPLICATION_CREDENTIALS: $env:GOOGLE_APPLICATION_CREDENTIALS" -ForegroundColor Green
  if(Test-Path $env:GOOGLE_APPLICATION_CREDENTIALS){
    Write-Host "  ✓ ファイル存在確認: OK" -ForegroundColor Green
  } else {
    Write-Host "  ✗ ファイルが見つかりません" -ForegroundColor Red
  }
} else {
  Write-Host "  ✗ 環境変数未設定" -ForegroundColor Red
}

# 5) ログ確認
Write-Host "`n[5] ログ確認（最新20行）" -ForegroundColor Yellow
$log = Join-Path $env:APPDATA "OcrSnippingApp\Logs\OcrSnippingApp_$(Get-Date -Format 'yyyyMMdd').log"
if(Test-Path $log){
  Write-Host "  ✓ ログ: $log" -ForegroundColor Green
  Write-Host "`n  --- 最新ログ ---" -ForegroundColor Gray
  Get-Content $log -Tail 20 -Encoding UTF8 | ForEach-Object { Write-Host "  $_" -ForegroundColor Gray }
} else {
  Write-Host "  ✗ ログなし: $log" -ForegroundColor Red
}

Write-Host "`n========================================" -ForegroundColor Cyan
Write-Host "診断完了" -ForegroundColor Cyan
Write-Host "========================================`n" -ForegroundColor Cyan
```
