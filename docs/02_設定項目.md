## 6. 設定項目（既定値）

| 項目 | 既定値 | 説明 |
|------|--------|------|
| `HotkeyModifiers` | 空文字 | グローバルホットキー修飾子。空ならホットキー無効 |
| `HotkeyKey` | 空文字 | グローバルホットキー本体キー |
| `OcrMode` | `DocumentTextDetection` | Vision API の OCR モード |
| `Notifications` | `true` | OCR 完了時のバルーン通知 |
| `TimeoutMs` | `10000` | Vision API 呼び出しタイムアウト (ms) |
| `LanguageHint` | `ja` | Vision API の言語ヒント |
| `AppendModeEnabled` | `false` | 追記モードの可否 (詳細は下記) |
| `PrefixText` | 空文字 | 追記モード時に OCR 結果の前に付与するテキスト (最大5000文字) |
| `SuffixText` | 空文字 | 追記モード時に末尾へ付与するテキスト (最大5000文字) |
| `AddBlankLines` | `true` | 追記モード時に各テキストと本文の間へ空行を自動挿入 |

### 6.1 追記モード仕様

- `AppendModeEnabled` が `true` の場合にのみ有効。
- 合成順序: `PrefixText` → (必要なら空行) → OCR本文 → (必要なら空行) → `SuffixText`。
- 空行 (`Environment.NewLine`) は `AddBlankLines` が `true` のとき、かつ前後テキストが空でない場合に付与。
- `PrefixText` / `SuffixText` はそれぞれ 5000 文字まで。超過時は自動的に切り詰め、ログに警告を出力。
- 合成後の全文がクリップボードへコピーされ、ログに `append=true/false` が記録される。

## 7. 受入基準（抜粋）

A-01: 初回起動後、トレイアイコンが表示される。

A-02: Ctrl+Alt+C で矩形選択が起動し、Escで必ずキャンセルできる。

A-03: テキストを含む領域を選択した場合、2秒以内にクリップボードへコピーされる（テスト回線）。

A-04: ImageAnnotatorClient.Create() はプロセス内で一度のみ呼ばれることをログで確認。

A-05: 鍵ファイル未設定時に安全に失敗し、明確なメッセージを表示。

A-06: 4K＋100%/150%混在環境で矩形選択と切り出し位置ずれが発生しない。
A-07: 追記モード有効時、`PrefixText` / `SuffixText` / `AddBlankLines` が設定どおりに適用され、既存の OCR 本文は改変されない。
