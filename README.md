# OcrSnippingApp
READMEを書いて
OcrSnippingAppは、画面の一部をキャプチャしてGoogle Cloud Vision APIを使用してOCR（光学文字認識）を行うWindowsアプリケーションです。本アプリケーションは、タスクトレイから操作可能で、キャプチャした画像からテキストを抽出し、クリップボードにコピーします。

## 🚀 主な機能
- 画面キャプチャ: 任意の画面領域を選択してキャプチャします。
- OCR処理: Google Cloud Vision APIを使用してキャプチャした画像からテキストを抽出します。
- タスクトレイ統合: アプリケーションはタスクトレイに常駐し、簡単にアクセスできます。
- 設定可能なホットキー: ユーザーはホットキーを設定して、素早くキャプチャを開始できます。
- 結果のコピー: 抽出したテキストはクリップボードにコピーされ、他のアプリケーションで簡単に利用できます。
## 🔒 セキュリティ仕様
- 認証情報の管理: Google Cloud Vision APIを使用するための認証情報は、ユーザーのローカル環境に安全に保存されます。
- データの暗号化: キャプチャした画像や抽出したテキストは、必要に応じて暗号化され、セキュリティが強化されます。  
- ネットワーク通信の保護: API呼び出しはHTTPSを使用して行われ、データの盗聴や改ざんを防止します。
- ログ管理: アプリケーションのログには機密情報を含めず、必要最低限の情報のみを記録します。
- **認証情報**: ログに含めない
- **キャプチャ画像**: ログに含めない
- **抽出テキスト**: ログに含めない
